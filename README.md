# Публичные исходники патчевого классификатора

Этот комплект содержит код инференса, архитектуру классификационной головы,
параметры обработки, зависимости и синтетический RGB224-пример.
**Веса Phikon-v2 и обученной головы не включены. Без них инференс невозможен.**

Установка, проверка исходников и размещение разрешённых локальных весов:
[RUN.md](RUN.md). Условия внешней модели и атрибуция: [NOTICE.md](NOTICE.md).

Быстрая проверка файлов без загрузки модели и без ML-библиотек:

```powershell
py -3.11 -B .\verify_package.py
```

`examples/synthetic.png` — геометрический тестовый вход без медицинских данных.
Он служит только для проверки запуска; оценку качества модели не заменяет.
Каталог `weights/` и распространённые форматы весов исключены из Git.
